# Colonia Nova · prototipo v0

Prototipo desechable para responder una pregunta: **¿es divertido construir de día y sobrevivir de noche?**

- Día: recoge chatarra (rocas doradas) y construye torretas (25 de chatarra).
- Noche: oleadas de alienígenas atacan el núcleo; el astronauta dispara solo.
- Cristales por noche sobrevivida y por jefes (cada 3 noches); mejoras permanentes al perder.

Para jugarlo, abre `index.html` en el navegador. Es código de prueba: si la idea funciona, el juego de verdad se rehace bien, no se reutiliza este archivo.
